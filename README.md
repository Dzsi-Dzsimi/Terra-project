This game was made using Godot Engine version 4.7, and is available at itch.io: https://dzsi-dzimi.itch.io/chud-v-chad-game
10 hours were spent total on this game, with the first 4 hours worth of progress being lost and re-developed
- All assets were made by hand using piskel.com, a free, open-source web and desktop application designed for creating 2D pixel art and animated sprites
